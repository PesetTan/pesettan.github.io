Add the custom element

  1. Use a duplicate or test page. Add a Custom Element in Wix and set its tag to inbrnd-flywheel.
  2. Choose Server URL and use https://pesettan.github.io/inbrnd/inbrnd-flywheel.js, or copy the bundled JavaScript into a Velo custom-element file.
  3. Set the attributes below. Use content-mode="diagram" for the circle-only presentation.
  4. Allow the host section to grow with its content. The component contains only the flywheel section: diagram, active-stage explanation, final payoff, and reading option. It supplies its own sticky frame and normal document scrolling. Do not constrain the entire element to one screen or place it in a separately scrolling iframe.
asset-base: https://pesettan.github.io/inbrnd/assets/
variant: wheel
emphasis: ring
content-mode: teaching
heading-level: 2
header-offset: 0

Set header-offset to the measured height of a sticky Wix header, when present. The desktop journey remains 5.75 viewport heights and the mobile journey 7, before the other page content. Short screens use an unpinned complete framework.

What changes as you scroll

The five-stage system completes at 80% of the existing journey. The teaching sentence appears from 80–85%, then the full composition remains visible through 100%. The pink ring gradually becomes burgundy; its stroke grows from 12 to 13 SVG units. Reverse scrolling restores each state precisely.

Verify the published test page

  1. Check forward and reverse scrolling, the scroll sequence and reading option, the completed hold, and the next section.
  2. Inspect desktop, tablet, phone, and landscape. Confirm text, arrows, and curved labels do not overlap or clip.
  3. Test reduced motion, keyboard access, Read without motion, and font loading while logged out.
  4. Check the host wrapper's height and overflow on a published Wix test page. Editor Preview alone is not proof of the installed behavior.

Static fallback and rollback

The standalone HTML examples contain a complete static diagram and five explanations before JavaScript initializes. A Wix Editor custom element does not automatically inherit this surrounding HTML; validate the equivalent host-page fallback during installation.
